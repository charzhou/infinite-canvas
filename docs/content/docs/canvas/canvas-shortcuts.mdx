# Canvas Shortcuts

## View

- Use the pointer button in the bottom toolbar for Select mode and the hand button for Move mode. The canvas starts in Move mode.
- In Move mode, drag empty canvas space to pan.
- Hold `Ctrl` or `Space` to temporarily invert Select / Move mode; release to restore the selected mode.
- Use the mouse wheel or zoom slider to zoom.
- Use Reset View to restore the default zoom and centered position.

## Selection

- In Select mode, drag empty canvas space to box-select multiple nodes.
- Hold `Shift` while box-selecting to add nodes to the existing selection.
- `Shift / Ctrl / Cmd` + click: add or remove a node from the selection.
- `Ctrl / Cmd` + `A`: select all nodes.
- `Esc`: clear the selection and close the active overlay.

## Editing

- `Ctrl / Cmd` + `C`: copy selected nodes.
- `Ctrl / Cmd` + `V`: paste nodes.
- `Ctrl / Cmd` + `G`: group selected nodes.
- `Ctrl / Cmd` + `Shift` + `G`: ungroup the selection.
- `Delete / Backspace`: delete selected nodes or edges.
- `Ctrl / Cmd` + `Z`: undo.
- `Ctrl / Cmd` + `Shift` + `Z`, or `Ctrl / Cmd` + `Y`: redo.

Drag image files onto the canvas to upload them, or insert saved items from My Assets. Undo and redo cover nodes, edges, the viewport, background mode, and assistant sessions; they do not cover the project name, account state, global AI settings, or the My Assets library.
