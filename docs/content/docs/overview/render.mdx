# Deploy on Render

Render builds the Docker image from the repository's root `render.yaml`. Configure the OIDC variables as secrets in the Render dashboard: `OIDC_ISSUER`, `OIDC_GATEWAY_BASE_URL`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_SESSION_KEY`, `OIDC_PROVIDER_NAME`, and `PUBLIC_ORIGIN`. Set `OIDC_PROXY_TIMEOUT_MS` to `600000` (10 minutes).

`OIDC_ISSUER` remains the canonical issuer, for example `https://ai.nekotech.us`. `OIDC_GATEWAY_BASE_URL` is an optional restricted gateway endpoint and defaults to the issuer when omitted. To accelerate compute requests through a CDN, set it to `https://sub2api.tegical.com`. Any CDN or reverse proxy in front of it must pass through `Authorization: Bearer`, streaming responses, `Range`, and binary media content, and must not cache authenticated API responses by default. Set `PUBLIC_ORIGIN` to the HTTPS domain assigned or attached by Render, and register the exact callback `{PUBLIC_ORIGIN}/api/oidc/callback` at the provider. Users select models before connecting, and the BFF requests scopes only for those models; the Sub2API OAuth client still rejects models outside its `allowed_llm_scopes`. Changing models starts authorization again. Without these variables, a Render deployment can still use manual API key channels.

[Deploy to Render](https://render.com/deploy?repo=https://github.com/basketikun/infinite-canvas)

1. Select **Deploy to Render**.
2. Sign in and connect GitHub as prompted.
3. Confirm the deployment.

When deployment finishes, open the assigned `.onrender.com` domain.

The default configuration uses Render's free Web Service. It sleeps after a period of inactivity and wakes on the next request. Application data is primarily stored in the browser, and prompt repositories are fetched by the frontend. The free tier is suitable for evaluation and demos; use Vercel or configure WebDAV for longer-term use.
